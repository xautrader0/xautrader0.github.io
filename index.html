MINI JARVIS

A personal production dashboard for one creator's own channels

Mini JARVIS is a private, non-commercial desktop application. It runs only on its owner's own Windows PC and is not offered to the public.

What it does

  • Manages the owner's short-form video production: queues work, checks that every rendered video is valid and files it into the right folder.
  • Shows the owner's brand assets (profile pictures, banners, bios) from their own project folders.
  • Shows read-only statistics for the owner's own YouTube channels, TikTok accounts and Instagram / Facebook Page, so performance can be compared across projects in one place.

How account access works

The owner connects each of their own accounts through the platform's official sign-in page (OAuth 2.0). Mini JARVIS never sees or stores account passwords, and only requests read-only permissions: it cannot post, schedule, edit or delete anything through these connections.

Statistics and sign-in tokens are stored only on the owner's PC. Tokens are encrypted with Windows data protection. Nothing is sent to any server operated by Mini JARVIS, because none exists.
